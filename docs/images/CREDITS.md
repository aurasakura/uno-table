# Uno Dos Tres visual credits

These README visuals were rendered from the supplied `Common-Ground-Table-all-documents 2.html` project document. The document used an earlier working name; the product and team are now **Uno Dos Tres**.

- `how-it-works.png`: the document's animated hardware diagram, captured as a static concept illustration. The subtitle and recognition step were clarified for the README. Laptop output is illustrative, not a live log.
- `effects-mockup.png`: the document's browser table mockup, captured with blue and draw-two effects. This is an interface illustration, not a physical-test photograph.
- `heritage-games.png`: the roadmap's game gallery, laid out in three columns for readability. Embedded photographs were reused from the supplied document; other cards use text and illustrations. Planned features are not implemented support.
